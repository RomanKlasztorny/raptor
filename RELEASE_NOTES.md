# RAPTOR Compact v1.2.0-compact

Небольшой релиз локального конструктора архитектуры.

- Переносимая версия приложения: index.html, app.js и необязательный llm-proxy.js.
- Стили и изображение питомца встроены; доступен экспорт Word без CDN.
- Подробная самодостаточная инструкция RAPTOR_AI_JSON_GUIDE.md для генерации JSON в любом AI-чате.
- Полный пример проекта: REST, SQL/ERD, Redis, Kafka, C3 и BPMN.
- Скрипт повторной упаковки и генератор справочника.
- Встроенный API-ключ удалён из публикуемой копии.

## Запуск

Распакуйте архив и откройте index.html. Для HTTP-запуска: npx serve . -p 5500.
Облачным AI-провайдерам при необходимости: node llm-proxy.js.
Для генерации схемы приложите MD в AI-чат вместе с описанием архитектуры, сохраните JSON и импортируйте его через меню RAPTOR.

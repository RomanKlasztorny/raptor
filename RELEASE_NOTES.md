# RAPTOR v1.1.3 — тестовый предрелиз

**Проект не заброшен — разработка продолжается.** Эта сборка опубликована для тестирования компактной версии и сбора обратной связи. Следующее обновление **v1.1.4 готовится и выйдет скоро**; точную дату сообщим отдельно.

## Что можно попробовать

- Компактный RAPTOR: `index.html`, `app.js` и необязательный AI-прокси `llm-proxy.js`.
- Архитектурные схемы, C1–C4, сценарии и Sequence, схемы БД, Redis, Kafka и BPMN.
- Подробную инструкцию **RAPTOR_AI_JSON_GUIDE.md**: приложите её в любой AI-чат вместе с описанием архитектуры, получите JSON и импортируйте файл в RAPTOR.
- Готовый пример JSON с REST, SQL/ERD, Redis, Kafka, C3 и BPMN.

MD и пример входят в ZIP и доступны отдельными вложениями. Стили и изображение питомца встроены. Встроенный API-ключ удалён — свой можно указать в интерфейсе.

## Запуск

1. Скачайте `raptor-compact-v1.1.3.zip` и распакуйте.
2. Откройте `index.html`. Для HTTP-запуска: `npx serve . -p 5500`.
3. Если нужен облачный AI-прокси: `node llm-proxy.js`.
4. JSON загружайте через меню импорта файла — этот путь сохраняет богатую модель проекта.

## Тестовый статус

**Это предрелиз для тестирования, а не финальная стабильная сборка.** Возможны ошибки и шероховатости интерфейса. Перед экспериментами экспортируйте важные проекты в JSON.

Проверено: 71 тест движка, синтаксис пакета, загрузка примера настоящим файловым импортёром; BPMN-валидатор — 0 замечаний. Полный браузерный smoke-тест этой сборки пока не выполнялся.
